# Ultrahuman gifting: hero + highlights carousel

Clickable prototype. Open `index.html` (hash routes). Source is `src.html`; `python3 build.py` inlines the images and writes `index.html`.

- Hero: hand and gold gift card over a centred gold frost gradient.
- Carousel: five highlight cards (Sleep, Recovery, Movement, Heart rate, Powerplugs) using Phoenix and Gifting Flow elements.
